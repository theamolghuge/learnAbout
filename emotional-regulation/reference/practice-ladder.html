The Practice Ladder

Nine rungs, 5–15 min each, ordinary life only. From Lesson 9. Print and check off as you go.

  • 1. Low-stakes irritation — label it silently, no action needed. 3×/week.
  • 2. Mild anxiety — 10-second version before a small dreaded task, then do it anyway.
  • 3. Interpersonal friction — 2-minute version + 3 options before responding to a minor disagreement.
  • 4. Criticism — ask for honest feedback; label the sting in real time.
  • 5. Uncertainty — leave one small decision open 24 hours on purpose.
  • 6. Rejection — ask for something that might be a no; delay interpreting it if it is.
  • 7. Anger — full 2-minute version on a real one; log it either way.
  • 8. Fear of loss — name what you're avoiding; run the Lesson 4 checklist on it in writing.
  • 9. High-stakes decisions — full 20-minute version + log entry, on something actually live.
Rule Move up a rung only once the one below starts happening without deciding to. Skipping ahead trains the skill at a difficulty it hasn't earned yet.
