The Practice That Makes It Stick

Nineteen lessons of tools compound into nothing without a structure that runs whether or not you feel like using them today.

Every tool so far works when you remember to reach for it. This lesson isn't a new tool — it's the schedule that makes reaching for them automatic instead of occasional. Four cadences, each already built mostly from pieces you have.

Real-time practice — already built

You already have this one. It's Lesson 9's protocol, unchanged: Feel it. Name it. Check it. Then act. Whenever something charged happens, that's the whole real-time practice. Nothing new needed here — just the reminder that this is the one you use in the moment, not the ones below.

Daily practice — 10 to 20 minutes

  1. Morning (2 minutes): name one specific thing you'll watch for today — a chala trick in a conversation, a moment of avoidance, an unexamined constraint you've been treating as fixed. One thing, named specifically, not a vague intention to "be more mindful."
  2. Evening (10-15 minutes): one journal entry, using the decision journal or belief journal template — whichever fits something that actually happened today. Not both, every day; one real entry beats two rushed ones.
  3. Attribution check (2 minutes): however today's biggest success or setback went, write one sentence on how you explained it to yourself. Run it against Lesson 15's self-serving bias question: would I explain someone else's identical outcome the same way?

Weekly practice — 30 to 45 minutes

Read back through the week's journal entries in one sitting. Look specifically for repetition: which hetvabhasa or modern bias shows up more than once? Which chala do you keep falling for, in either direction? Which decisions, in hindsight, skipped a step from Lesson 5's method — and would the skipped step have changed anything? Pick exactly one recurring pattern to watch for specifically next week. Not three. One, held long enough to actually notice it forming in real time.

Monthly practice — 60 to 90 minutes

  • Run Lesson 7's calendar-and-wallet check properly, as a ritual, not a one-off — has revealed behavior shifted, and does it still match stated priorities?
  • Run Lesson 8's avoidance scan — over the past month, what topics produced dread, deflection, or chronic delay?
  • Skim the glossary and honestly mark which terms you've actually used this month versus which remain theoretical. A term you haven't reached for in a month is a term worth deliberately practicing, not one to assume you've internalized.

Retrieval check

What is the real-time practice, and where does it come from?

"Feel it, name it, check it, then act" — from Lesson 9.

How many recurring patterns should a weekly review target?

One — held long enough to actually notice it forming.

What determines whether a glossary term needs deliberate practice?

Whether you've actually used it that month, not just read it.

Drill (do this now — ~15 minutes)

Run today's daily practice, right now

  1. Name the one specific thing you'll watch for over the rest of today.
  2. Write one journal entry — a real decision or belief from the last day or two — using whichever template at Decision Journal or Belief Journal fits.
  3. Write the attribution-check sentence for today's most significant outcome so far.

Check your work: if the journal entry took under three minutes, it's probably too shallow to be useful later — a real entry should feel like it took some actual thought, not like filling in a form.
