The Operating System

Twenty-one lessons compressed to one page. This is the last new thing in the course — everything from here is practice.

The measure of this course was never "do I understand Anvikshiki." It was the line from the very start: examine before concluding, question before believing, distinguish fact from interpretation, recognize uncertainty, revise beliefs when evidence changes, deliberate before acting, and learn from what actually happens next. That's not a summary you read once. It's a description of a page you should be able to use without the other twenty-one lessons behind it.

The page

Reference: Anvikshiki Operating System — ten principles, ten questions, ten behavioral rules, ten red flags, ten recovery protocols, and four compact protocols for decisions, conflict, emotion, and belief-updating. Every line traces back to a specific lesson if you need the fuller version.

The actual test

Not a quiz this time. Print the operating system page, or keep it open, and use only it — not this lesson, not the other twenty-one — the next time something real happens: a decision, a disagreement, a strong emotion, a claim you're tempted to believe or share. If the page is enough, the course did its job. If it isn't, that's not a failure of the page — it's the signal for exactly which lesson to revisit, and the glossary and lesson links on the page will point you there directly.

What happens after this Nothing dramatic. The remaining work is the daily, weekly, and monthly practice from Lesson 20, run for real, over time — not more lessons to read. Reread MISSION.md's "Success looks like" list occasionally; that's the actual finish line, and it's measured in what you do, not in what you've read.

Drill (do this over the next real situation, whenever it happens)

Use only the operating system page

  1. Keep the operating system page open or printed.
  2. The next time something real happens — a decision, a conflict, a strong emotion, a claim worth checking — use only that page to work through it.
  3. Afterward, write one honest note: did the page carry the whole way, or did you need to go back to a specific lesson? If so, which one, and why.

Check your work: needing to go back to a lesson isn't a failure of this drill — it's data about which page needs to be more familiar before it can run on its own. Note it, revisit that lesson, and try again next time.

Stuck, or want to go further? Ask me anything — a real situation you want to work through together, or which lesson to revisit if the operating system page wasn't enough on its own. I'm your teacher here, not just a document; use me, for as long as this is useful.
