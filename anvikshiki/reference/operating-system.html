Anvikshiki Operating System

Everything else in this course, compressed to one page. The goal was always this page working without the other twenty-one lessons behind it — go back to them only when this isn't enough.

10 core principles

  1. A belief without a hetu is unexamined, not known.
  2. Name the pramana before trusting a claim — including your own self-talk.
  3. An inference is only as strong as its vyapti — find the counter-example on purpose.
  4. Confirmation bias is what happens the moment you stop looking for that counter-example.
  5. Intent is never observed, only inferred.
  6. The emotion isn't the problem; the unexamined belief underneath it is.
  7. Suspension is a temporary state pending a tiebreaker, not a permanent home.
  8. Reversibility, not confidence, should size how much evidence you gather before acting.
  9. Character is what a repeated, examined pattern becomes — judge the pattern, not just the instance.
  10. Examined reasoning keeps the mind steady, not cold. Feel it, then check it.

10 questions, for whenever something important happens

  1. What did I actually observe, versus what did I infer?
  2. What's the hetu — and is it mine, or inherited?
  3. Which pramana is this resting on?
  4. Is there a real counter-example to the rule I'm relying on?
  5. What am I ignoring that's directly observable?
  6. Who is affected, and what do I actually know about them versus infer?
  7. What's the worst case, and is this reversible?
  8. Would I endorse this after reflection, from the witness stance?
  9. What happens if I do this the same way for years?
  10. What would actually change my mind here?

10 behavioral rules

  1. State the claim precisely before accepting or rejecting it.
  2. Before trusting testimony — including your own — run the apta test.
  3. Actively hunt for a counter-example before calling a rule established.
  4. Strong emotion: feel it, name it, check it, then act.
  5. Never treat a claim about someone's intent as fact — ask, don't assume.
  6. Size your response to what's verified, not to how strong the feeling is.
  7. Match a decision's tiebreaker to its reversibility.
  8. Journal real decisions and real examined beliefs — not everything, just the real checks.
  9. Run "repeated for years" on anything you're tempted to call a harmless one-off.
  10. When stuck after one honest pass with no new evidence, act on the best available verdict.

10 red flags — reasoning has gone distorted

  1. Certainty arrived unusually fast.
  2. You can't actually state the counter-example you supposedly looked for.
  3. The same belief keeps needing re-litigating with no new evidence.
  4. You're explaining your own outcome differently than you'd explain someone else's identical one.
  5. One specific topic reliably produces dread, deflection, or delay.
  6. You're still "thinking about it" long after every real check has already run.
  7. The word "everyone" is doing the evidentiary work in an argument.
  8. You've stopped checking sources and started defaulting to disbelief on principle.
  9. An emotion drove an action with nothing in between.
  10. You'd be embarrassed to write today's reasoning down and reread it in a month.

10 recovery protocols — after realizing a mistake

  1. Run the mistake review — find the specific step that broke, not just "I was wrong."
  2. Separate outcome from reasoning quality — good process, bad luck isn't the same failure as bad process.
  3. Name which hetvabhasa or bias applied, specifically.
  4. Check whether this is a first occurrence or a pattern, against recent journal entries.
  5. Write one specific change — not a vague resolution to "do better."
  6. If someone else was affected, address it directly and specifically.
  7. Update the belief journal if a belief was involved, with the new verdict.
  8. Resist overcorrecting into the opposite failure — one bad trust call doesn't justify permanent cynicism.
  9. Set a review date if the fix needs testing — use the personal experiment template.
  10. Close the loop deliberately. Write the verdict, then stop — don't loop in rumination.

Morning practice — 2 minutes

Name one specific thing to watch for today — a chala trick in a conversation, a moment of avoidance, an unexamined constraint. One thing, specific, not a vague intention.

Evening practice — 12-17 minutes

One journal entry — decision or belief, whichever fits something real that happened today. One sentence on how you explained today's biggest success or setback, checked against the self-serving-bias question.

Decision protocol, compact

Objective (apta-tested) → options as pratijna + hetu → satpratipaksha check → reversibility → tiebreaker if genuinely tied → second-order effects → worst / best / likely case → decide, and journal it.

Conflict protocol, compact

Classify the exchange (vada, jalpa, or vitanda) → know / infer / don't know / ask → name any chala being used, out loud if useful → respond to content, not delivery → size the response to what's actually verified.

Emotional protocol, compact

Feel it → name it (viveka: "this is not me, it is not mine, I am not this") → check it (run the interpretation through the five-limb method) → then act.

Belief-update protocol, compact

State the pratijna → name the pramana → hunt the counter-example (vyapti) → check for hetvabhasa → accept, reject, or suspend with a named next step.
