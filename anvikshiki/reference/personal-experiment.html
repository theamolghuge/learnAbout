Personal Experiment

For testing whether a belief or habit is actually producing what you think it is — the five-limb method, run forward instead of backward.

Every other tool in this course examines a belief you already hold. This one is for when you're not sure, and the honest move is to generate new evidence on purpose rather than reason harder about evidence you already have.

Template

The belief or habit being testedStated as a pratijna — precise enough to be checkable.
If true, I should observeA specific, concrete, pratyaksha-level prediction — not a feeling, an observable.
If false, I should observeThe counter-prediction — what would actually show this belief is wrong, stated in advance, before you can rationalize the result either way.
The testWhat you'll actually do, and for how long — a defined window, not "for a while."
What would make this not a fair testConfounds you should watch for — anything else changing at the same time that could produce the same result for a different reason.
Result, filled in after the windowWhat actually happened — pratyaksha, recorded as observed, not as remembered afterward.
VerdictAccept, reject, or genuinely inconclusive (a real, honest option — not every experiment resolves cleanly).
Not a real experiment: "I'll try waking up earlier and see how it goes." No prediction stated in advance, no defined window, no way to fail — "see how it goes" can be declared a success no matter what happens.
A real experiment: "If waking at 6am actually improves my focus, I should notice fewer distracted moments during my 9-11am work block, self-rated on a simple 1-5 scale, averaged over two weeks. If it doesn't, that average won't move. Confound to watch: any change in sleep total, not just wake time."

Built from Lesson 5 and Lesson 12's tiebreaker logic — a real trial that generates pratyaksha, matched to a fair, pre-committed test of failure.
