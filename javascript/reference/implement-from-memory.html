Drill session (60 min)

  1. Pick 2 from JavaScript (debounce + Promise.all)
  2. Pick 1 from Node (rate limiter or cache-aside)
  3. Pick 1 from React (custom useFetch or controlled form)
  4. Pick 1 from Next.js (Server Action or middleware auth)
  5. Pick 1 TypeScript (discriminated union or generic utility)
  6. Say out loud: event loop order, auth vs authz, React Query vs Redux

Self-check questions

  • Did I handle edge cases (empty array, zero delay, unmount)?
  • Did I use this correctly in debounce/throttle?
  • Did Node middleware call next() or send response?
  • Did React effect return cleanup?
  • Did TypeScript narrow before using unknown?
