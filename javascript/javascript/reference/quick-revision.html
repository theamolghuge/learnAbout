30-second answers

Execution context vs call stack?
Each function call creates an execution context (variables, outer env, this). The call stack holds active contexts — last in, first out.

Event bubbling vs capturing?
Capture: root → target. Bubble: target → root (default). Delegation: listen on parent, use event.target.

What is a closure?
A function that retains access to outer scope variables after the outer function returns.

Debounce vs throttle?
Debounce fires after triggers stop (search). Throttle fires at most once per window (scroll).

Implement from memory

  • debounce & throttle
  • curry · memoize · bind · Promise.all
  • flatten array · deep clone (WeakMap)
