30-second answers

Why Next.js over Vite SPA?
SSR/SSG for SEO and fast FCP, Server Components reduce client JS, file routing, API colocation, built-in optimizations, production deployment story.

Where to put "use client"?
As deep as possible — only components that need interactivity. Pages and layouts stay Server Components; import Client leaves for buttons, forms with local state.

How does caching work?
fetch cached by default (Data cache). revalidate for ISR. no-store for dynamic. revalidatePath/Tag after mutations. Router cache on client for prefetched nav.
