Concepts in HTML & CSS Notes.

HTML · Semantic · A11y · CSS · Layout · Responsive

HTML

What is the purpose of the DOCTYPE declaration?

Tells the browser to render in standards mode (HTML5: <!DOCTYPE html>). Without it, browsers may use quirks mode with inconsistent layout. Always first line of document.

What does the viewport meta tag do?

<meta name="viewport" content="width=device-width, initial-scale=1"> — sets viewport width to device width for responsive mobile layouts. Without it, mobile browsers render at desktop width then scale down.

Difference between block and inline elements?

Block: starts new line, takes full width (div, p, h1). Inline: flows in text line, width by content (span, a, strong). Inline-block combines both. CSS display can change behavior.

Semantic HTML

Why use semantic HTML?

Clear meaning for browsers, screen readers, and search engines. Better accessibility without extra ARIA. Easier maintenance than div soup. Examples: nav, main, article, button vs styled divs.

When to use article vs section?

article — self-contained content that could stand alone (blog post, comment). section — thematic grouping within a page, usually with a heading. Article can contain sections; section can contain articles.

Accessibility

How do you make a form accessible?

Every input has associated <label for="id">. Group related fields with fieldset/legend. Use correct input types. Show validation errors linked with aria-describedby. Ensure keyboard submission works. Don't rely on color alone for errors.

When should you use ARIA?

When native HTML can't express the pattern — custom widgets, live regions, expanded/collapsed state. First rule of ARIA: don't use ARIA if native HTML works. Never use ARIA instead of semantic elements.

CSS

Explain the CSS box model.

Every element is a box: content → padding → border → margin. box-sizing: content-box (default): width is content only. border-box: width includes padding and border — predictable sizing. Use border-box globally.

How does CSS specificity work?

Inline styles beat IDs beat classes/attributes/pseudo-classes beat elements. Calculated as (inline, ID, class, element). Equal specificity → last rule in source wins. Avoid !important except utilities/overrides.

Difference between display: none and visibility: hidden?

display: none — removed from layout, takes no space, not focusable. visibility: hidden — invisible but still occupies space in layout. Use hidden attribute or aria for accessible hiding patterns.

Explain position absolute vs relative.

relative — offset from normal position, original space preserved. absolute — removed from flow, positioned relative to nearest ancestor with position not static. Common pattern: relative parent + absolute child for overlays/badges.

Flexbox & Grid

Flexbox vs CSS Grid — when to use which?

Flexbox: one-dimensional — nav bars, centering, distributing items in a row/column. Grid: two-dimensional — page layouts, card grids with rows and columns. Often combined — Grid for page shell, Flexbox for components.

How do you center a div horizontally and vertically?

Flexbox: display: flex; justify-content: center; align-items: center; min-height: 100vh;. Grid: display: grid; place-items: center;. Modern and interview-friendly — avoid negative margins or transform hacks.

What does flex: 1 mean?

Shorthand for flex: 1 1 0% — grow equally, shrink equally, zero basis. Items share available space. flex: auto uses content size as basis. flex: none prevents grow/shrink.

Responsive & Modern

Mobile-first vs desktop-first CSS?

Mobile-first: base styles for small screens, min-width media queries add complexity for larger. Progressive enhancement — recommended. Desktop-first uses max-width queries to scale down — harder to maintain.

rem vs em vs px?

px — absolute pixels. rem — relative to root font size (accessible, scales with user settings). em — relative to parent font size (compounds nested). Prefer rem for spacing/typography; px for borders/shadows.

What is BEM?

Block Element Modifier naming: .card, .card__title, .card--featured. Avoids specificity wars, clear component structure. Alternative to CSS Modules scoping or Tailwind utilities in modern React apps.
