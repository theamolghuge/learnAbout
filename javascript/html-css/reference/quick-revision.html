Center a div (memorize)

/* Flex */
.parent {
  display: flex;
  justify-content: center;
  align-items: center;
  min-height: 100vh;
}

/* Grid */
.parent {
  display: grid;
  place-items: center;
  min-height: 100vh;
}

30-second answers

Box model?
Content, padding, border, margin. Use border-box so width includes padding and border.

Flexbox vs Grid?
Flex: one axis, components. Grid: two axes, page layouts. Often used together.

Semantic HTML?
Elements that describe meaning — better SEO, a11y, maintenance than div soup.

Accessible form?
Labels linked to inputs, fieldset for groups, correct types, keyboard works, errors not color-only.
