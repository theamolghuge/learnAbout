  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Page Title</title>
  <meta name="description" content="...">
  <link rel="stylesheet" href="styles.css">
</head>
<body>
  ...
</body>
</html>
ElementUse
<div>Generic block container — no semantics
<span>Generic inline container
<a href>Links — use meaningful text, not "click here"

2. Semantic HTML

Semantic elements describe meaning — better for SEO, screen readers, and maintainability.

<header>Site logo, nav</header>
<nav aria-label="Main">...</nav>
<main>
  <article>
    <h1>Post title</h1>
    <section>...</section>
  </article>
  <aside>Related links</aside>
</main>
<footer>Copyright</footer>
BadGood
<div class="header"><header>
<div onclick> for button<button>
Skip heading levels h1 → h3Logical h1 → h2 → h3 hierarchy
Multiple h1 per page (debated)One h1 per page/section (App Router: per route)

3. Forms

<form action="/submit" method="post">
  <label for="email">Email</label>
  <input type="email" id="email" name="email" required autocomplete="email">

  <label for="pwd">Password</label>
  <input type="password" id="pwd" name="password" minlength="8" required>

  <button type="submit">Sign in</button>
</form>
Input typeUse
email, url, telValidation + mobile keyboard
number, rangeNumeric input
checkbox, radioBoolean / single choice from group
fileFile upload — accept attribute
hiddenNon-visible data

Always: associate <label for="id"> with input id. Group radios with fieldset + legend.

4. Accessibility (a11y)

  • Semantic HTML — first line of defense
  • Alt text — descriptive for content images; empty alt for decorative
  • Keyboard — all interactive elements focusable and operable
  • Focus visible — don't remove outline without replacement
  • Color contrast — WCAG AA: 4.5:1 text, 3:1 large text
  • ARIA — when HTML insufficient: aria-label, aria-expanded, role
  • Skip link — jump to main content
<button aria-expanded="false" aria-controls="menu">Menu</button>
<ul id="menu" hidden>...</ul>

6. Box Model

/* content → padding → border → margin */
.box {
  width: 200px;
  padding: 16px;
  border: 1px solid #ccc;
  margin: 8px;
  box-sizing: border-box;  /* width INCLUDES padding+border — use everywhere */
}

box-sizing: border-box — industry standard. Without it, width: 200px + padding makes element wider than 200px.

7. Flexbox ⭐

One-dimensional layout — row OR column. Best for nav bars, centering, distributing space.

.container {
  display: flex;
  flex-direction: row;        /* row | column */
  justify-content: center;    /* main axis */
  align-items: center;        /* cross axis */
  gap: 1rem;
  flex-wrap: wrap;
}

.item {
  flex: 1;                    /* grow/shrink equally */
  flex: 0 0 200px;            /* fixed basis, no grow/shrink */
}
PropertyAxis
justify-contentMain axis distribution
align-itemsCross axis alignment
align-selfSingle item cross axis
flex-grow/shrink/basisItem sizing flexibility

8. CSS Grid ⭐

Two-dimensional layout — rows AND columns. Best for page layouts, dashboards, card grids.

.layout {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: auto 1fr auto;
  gap: 1rem;
  min-height: 100vh;
}

.header { grid-column: 1 / -1; }

/* Named areas */
.page {
  display: grid;
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
  grid-template-columns: 200px 1fr;
}
.sidebar { grid-area: sidebar; }

Flexbox vs Grid

FlexboxGrid
1 dimension2 dimensions
Content-driven sizingLayout-driven tracks
Nav, toolbars, centeringPage layout, complex grids

9. Responsive Design

/* Mobile-first — base styles for mobile, enhance for larger */
.container { padding: 1rem; }

@media (min-width: 768px) {
  .container { padding: 2rem; max-width: 720px; margin: 0 auto; }
}

@media (min-width: 1024px) {
  .container { max-width: 960px; }
}

/* Dark mode */
@media (prefers-color-scheme: dark) {
  :root { --bg: #1a1a1a; --text: #eee; }
}
  • Relative units: rem (root em), em, %, vw/vh
  • Fluid typography: clamp(1rem, 2vw + 1rem, 2rem)
  • Responsive images: max-width: 100%, srcset, sizes

10. Cascade & Specificity

Specificity (high to low): inline style → ID → class/attribute/pseudo-class → element/pseudo-element.

/* 0,1,0,1 = 1 class + 1 element */
.nav a { color: blue; }

/* 0,0,0,2 = 2 elements — LOSES to above */
header a { color: red; }

/* !important overrides — avoid in production */
  • Same specificity → last rule wins (source order)
  • Inheritance — color, font inherit; margin, padding don't
  • :root or CSS variables for theming

11. Modern CSS

:root {
  --color-primary: #2563eb;
  --spacing: 1rem;
}

.card {
  background: var(--color-primary);
  padding: var(--spacing);
}

/* Container queries — style by parent width */
.card-container { container-type: inline-size; }
@container (min-width: 400px) {
  .card { display: flex; }
}

/* Parent selector */
.card:has(img) { padding-top: 0; }

12. Performance & Web Vitals

  • CLS — reserve space for images (width/height or aspect-ratio)
  • LCP — optimize hero image, preload critical assets
  • Minimize unused CSS — purge in Tailwind, code-split
  • Avoid @import in CSS — blocks parallel loading
  • will-change sparingly — hints GPU layer
