30-second answers

Why PreparedStatement over Statement?
Params sent separately from SQL text — user input can't become SQL. Also faster on repeat execution.

Why index, but not on everything?
Speeds reads (O(log n)), but every write also updates the index — cost in write latency and disk space.

Dirty vs non-repeatable vs phantom read?
Dirty = uncommitted data seen. Non-repeatable = same row changes value. Phantom = new rows appear on re-query.

Implement from memory

  • Query: customers with zero orders (LEFT JOIN + IS NULL)
  • Query: top N by group (GROUP BY + HAVING + ORDER BY)
  • JDBC: open connection → PreparedStatement → ResultSet loop, try-with-resources
  • Explain a composite index leftmost-prefix example
