30-second answers

N+1 in one sentence?
Fetching a list, then lazily loading a related collection per item in a loop — 1 + N queries instead of 1 joined query.

Why override @ManyToOne to LAZY?
The EAGER default can silently pull large object graphs — explicit fetch (JOIN FETCH/@EntityGraph) per query is safer and predictable.

Why doesn't @Transactional roll back on IOException?
Checked exceptions don't trigger rollback by default — only unchecked ones, unless rollbackFor is set.

Implement from memory

  • Customer/Order @OneToMany + @ManyToOne with correct owning side
  • A JOIN FETCH JPQL query fixing an N+1
  • @RestControllerAdvice with a specific + a catch-all handler
  • A DTO with @NotBlank/@Email/@Size and its 400 error shape
