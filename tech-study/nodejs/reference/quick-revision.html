30-second answers

Event loop in Node?
libuv drives phases. nextTick and Promises run between phases. Blocking sync code stalls all I/O. Thread pool handles fs/crypto off main thread.

Streams vs readFile?
readFile loads entire file into memory. Streams process chunks with backpressure — essential for large files and HTTP piping.

Authentication vs authorization?
Authentication verifies identity (401). Authorization checks permissions (403). JWT proves identity; RBAC checks roles on routes.

Cache-aside pattern?
Check Redis → miss → query DB → write to Redis with TTL → return. Invalidate key on updates.
