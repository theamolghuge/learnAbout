30-second answers

Why multi-stage Dockerfile?
Build stage has JDK+Maven+source (large); runtime stage only has JRE+jar (small, less attack surface).

EC2 vs RDS for a database?
EC2 = you manage everything yourself. RDS = AWS manages patching/backups/failover for you.

Rolling vs blue-green?
Rolling = gradual, cheap, needs compat. Blue-green = instant cutover + rollback, costs double briefly.

CI/CD pipeline (30-second answer)

push → checkout → mvn clean verify (test)
     → mvn package → docker build → docker push
     → deploy to staging/prod
