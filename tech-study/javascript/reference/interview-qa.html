Types, Variables & Equality

What are the data types in JavaScript?

Seven primitives: undefined, null, boolean, number, bigint, string, and symbol. Everything else — plain objects, arrays, functions, dates, regex — is an object. typeof reports functions as "function" even though they are technically objects.

Is JavaScript pass-by-value or pass-by-reference?

Primitives are passed by value — the function gets a copy. Objects are passed by reference value — the reference (pointer) is copied, so the function and caller can both mutate the same object. Reassigning the parameter to a new object does not affect the caller's variable.

Why does typeof null return "object"?

A bug from the first JavaScript engine in 1995 — null was stored as a null pointer with type tag 0, same as objects. Fixing it would break existing code. Always use value === null to test for null.

What is the difference between == and ===?

=== (strict) compares type and value without conversion. == (loose) coerces types first — e.g. null == undefined is true, "5" == 5 is true, [] == false is true. Use === everywhere unless you have a deliberate reason for coercion.

What are all falsy values?

false, 0, -0, 0n, "" (empty string), null, undefined, and NaN. Only these eight. Surprisingly truthy: [], {}, "0", "false".

Difference between var, let, and const?

var is function-scoped, hoisted as undefined, and can be redeclared. let and const are block-scoped and sit in the Temporal Dead Zone until their line runs. const must be assigned at declaration but object/array contents can still be mutated. Rule: const by default, let when reassigning, avoid var.

What is the Temporal Dead Zone?

The period from the start of a block until a let or const declaration is reached and initialized. Accessing the variable name in the TDZ throws ReferenceError. Unlike var, which is hoisted as undefined.

Why is NaN === NaN false? How do you check for NaN?

IEEE 754 defines NaN as not equal to anything, including itself. Use Number.isNaN(value) (doesn't coerce) or Object.is(value, NaN). Avoid global isNaN() — it coerces: isNaN("hello") is true.

Difference between ?? and ||?

?? (nullish coalescing) falls back only on null or undefined. || falls back on any falsy value. Example: 0 ?? 1 is 0, but 0 || 1 is 1. Use ?? when 0 or "" are valid values.

What is optional chaining (?.)?

Safely accesses nested properties — returns undefined instead of throwing if any part of the chain is null or undefined. Works for properties (user?.address?.city), array indices (arr?.[0]), and method calls (callback?.()).

Scope, Hoisting & Closures

What is hoisting?

JavaScript processes declarations before running code. var is hoisted and initialized to undefined. Function declarations are fully hoisted (callable before their line). let and const are hoisted but remain in the TDZ until initialized.

What is an execution context?

The environment created when code runs — variable bindings, lexical outer reference (scope chain), and this binding. Each function call pushes a new context onto the call stack. When the function returns, its context is popped.

What is the call stack?

A LIFO structure holding active execution contexts. Synchronous code runs frame by frame. Too many nested calls overflow the stack. Async callbacks run later via the event loop — not on the current stack frame.

What is a closure?

A function that retains access to variables from its outer lexical scope even after the outer function has returned. The inner function "closes over" those variables. Used for: data privacy (module pattern), factory functions, event handlers, memoization, debounce/throttle timers, and partial application.

Why does var in a loop with setTimeout print the same number?

var is function-scoped — there is one shared i for all iterations. By the time callbacks run, the loop finished and i equals the final value (e.g. 3). Fix: use let (new binding per iteration), an IIFE to capture i, or pass i as an argument to a wrapper function.

What is lexical scope?

Scope is determined by where code is physically written, not where it is called. Inner functions can read variables from outer functions. The engine walks up the scope chain to find a binding — stopping at the first match or throwing ReferenceError.

What is an IIFE?

Immediately Invoked Function Expression — (function(){ ... })(). Runs right away and creates a private scope so variables inside don't leak to global. Common before block scope and ES modules existed. Still found in legacy code.

What is a higher-order function?

A function that takes another function as an argument and/or returns a function. Built-in examples: map, filter, reduce, sort. Custom examples: debounce, once, curry, memoize.

Give a real-world use case for closures.

Module pattern: outer function holds private state, returns public methods that close over it. Also: React hooks store state between renders via closures; debounce keeps a timer ID in closure; event handlers remember configuration without globals.

this, call, apply, bind

How is this determined?

By how the function is called (priority): (1) new → new object, (2) call/apply/bind → specified object, (3) obj.method() → obj, (4) plain call → undefined in strict mode or globalThis otherwise. Arrow functions ignore all rules and inherit this from the enclosing scope where they were written.

What happens when you do const fn = obj.method; fn()?

Implicit binding is lost — it becomes a plain function call. In strict mode, this is undefined, so this.name fails. Fix: obj.method.bind(obj), wrap in arrow function, or call as obj.method().

Difference between call, apply, and bind?

call(thisArg, arg1, arg2) — invokes immediately, args listed individually. apply(thisArg, [args]) — invokes immediately, args as array. bind(thisArg, ...args) — returns a new function with fixed this and optional pre-filled args; does not invoke until you call the result.

When use arrow functions vs regular functions?

Use arrows for callbacks needing lexical this (class methods passed to timers, array callbacks referencing outer this). Use regular functions for object methods needing dynamic this, constructors, generators, and when you need the arguments object or to use new.

What does new do?

(1) Creates a new empty object. (2) Sets its [[Prototype]] to Constructor.prototype. (3) Runs the constructor with this bound to that object. (4) Returns the object — unless the constructor explicitly returns a different object.

Prototypes & Classes

How does prototypal inheritance work?

Every object has an internal [[Prototype]] link (use Object.getPrototypeOf(obj)). When you access a property, JS checks the object itself, then walks up the prototype chain until it finds the property or reaches null. Constructor functions have a .prototype object; new links instances to it.

Difference between __proto__ and prototype?

prototype is a property on constructor functions — the object used as the prototype for instances created with new. __proto__ (deprecated; use Object.getPrototypeOf) is the actual prototype link on any object instance. Every object has [[Prototype]]; only functions have .prototype.

What does instanceof check?

Whether Constructor.prototype appears anywhere on the object's prototype chain. It answers "does this object inherit from this constructor?" — not whether new was literally used. Can be overridden with Symbol.hasInstance.

Are ES6 classes the same as Java classes?

No. ES6 classes are syntactic sugar over constructor functions and prototypes. Methods still live on ClassName.prototype. Inheritance is prototypal delegation, not copy-based classical inheritance. Under the hood: extends uses Object.create to link prototype chains.

Why call super() before this in a subclass?

The subclass instance isn't initialized until the parent constructor runs. super() invokes the parent constructor and sets up this. Accessing this before super() in a derived class throws ReferenceError.

hasOwnProperty vs in operator?

obj.hasOwnProperty("key") or Object.hasOwn(obj, "key") — checks only the object's own properties, not the prototype chain. "key" in obj — returns true if the property exists anywhere on the object or its prototype chain.

ES6+ & Modern Syntax

What is destructuring?

Extracting values from arrays or properties from objects into variables in one step. Supports defaults ({ x = 0 }), renaming ({ name: userName }), rest (...rest), and nesting. Commonly used for function parameters and unpacking API responses.

Difference between spread and rest?

Same ... syntax, opposite direction. Spread expands — copies array elements, merges objects, passes array as individual arguments. Rest collects — gathers remaining array elements or object properties, or collects extra function arguments into an array.

ES modules vs CommonJS?

ESM (import/export): static, hoisted imports, tree-shakeable, strict mode, async in browsers. CommonJS (require/module.exports): synchronous, dynamic, Node legacy. Modern Node supports both; bundlers convert between them.

What is a Symbol used for?

Creating guaranteed-unique property keys — Symbol("id") !== Symbol("id"). Not included in Object.keys, for...in, or JSON. Used for hidden metadata, well-known behaviors (Symbol.iterator, Symbol.toStringTag), and avoiding property name collisions.

What are generators?

Functions declared with function* that can pause and resume using yield. Return an iterator. Useful for lazy sequences, infinite series, and custom iteration. Each yield produces a value; calling .next() resumes until the next yield or return.

Async, Promises & Event Loop

Explain the event loop.

JavaScript runs synchronously on one call stack. When async operations complete (timers, fetch, I/O), their callbacks go into queues. When the stack is empty, the event loop drains all microtasks (Promise callbacks), then executes one macrotask (setTimeout, click handler), then repeats. This enables non-blocking async on a single thread.

Microtasks vs macrotasks?

Microtasks (run after current script, before next paint): Promise.then/catch/finally, queueMicrotask, MutationObserver. All microtasks drain before the next macrotask. Macrotasks (one per loop): setTimeout, setInterval, I/O, UI events. That's why Promise callbacks beat setTimeout(fn, 0).

Promise states and immutability?

Three states: pending, fulfilled, rejected. Once settled (fulfilled or rejected), the state and value/reason cannot change. Calling resolve then reject — only the first counts.

async/await vs Promises?

async/await is syntactic sugar. An async function always returns a Promise. await pauses that function until a Promise settles, then unwraps the value or throws the rejection. Same event loop behavior — easier to read, but you still need try/catch for errors. Under the hood it's Promises and microtasks.

Output order: sync, setTimeout(0), Promise.then?

Synchronous code first, then all Promise microtasks, then setTimeout macrotask. Classic: console.log(1); setTimeout(()=>log(2),0); Promise.resolve().then(()=>log(3)); console.log(4); → 1, 4, 3, 2.

Promise.all vs Promise.race vs Promise.allSettled?

all — waits for all to fulfill, returns array in order; rejects on first failure. race — settles when first promise settles (fulfill or reject). allSettled — waits for all, returns {status, value/reason} for each; never rejects. any — first fulfillment wins; rejects only if all reject.

How to run async operations in parallel with await?

Start promises first (don't await individually), then await together: const [a, b] = await Promise.all([fetchA(), fetchB()]). If you await inside a loop sequentially, each waits for the previous — much slower.

What is callback hell?

Deeply nested callbacks where each async step is inside the previous callback's success handler. Hard to read, hard to error-handle (must check errors at every level). Promises flatten this with chainable .then and a single .catch. async/await makes it read like synchronous code.

Arrays, Objects & Collections

map vs filter vs reduce?

map — transforms every element, returns new array of same length. filter — keeps elements where callback returns truthy, returns shorter (or equal) array. reduce — folds array into a single value (number, object, array) using an accumulator. None mutate the original array.

Which array methods mutate the original?

Mutating: push, pop, shift, unshift, splice, sort, reverse, fill. Non-mutating: map, filter, reduce, slice, concat, flat, flatMap, find, some, every. In React/immutable patterns, prefer non-mutating methods.

slice vs splice?

slice(start, end) — returns a shallow copy of a portion; does not mutate. splice(start, deleteCount, ...items) — removes/replaces/inserts elements in place; mutates the array and returns removed elements.

Why does [10, 2, 1].sort() give [1, 10, 2]?

Default sort converts elements to strings and compares lexicographically — "1" < "10" < "2". For numbers always pass: .sort((a, b) => a - b) for ascending, b - a for descending.

When use Map over a plain object?

When keys aren't strings/symbols (objects, functions as keys), you need guaranteed insertion order, frequent add/delete operations, or a built-in .size property. Plain objects are better for fixed-shape records and JSON serialization.

What is a Set?

Collection of unique values — duplicates are ignored on add. Dedupe an array: [...new Set(arr)]. Fast .has() membership checks. No key-value pairs — just values.

Shallow copy vs deep copy?

Shallow (spread, Object.assign, Array.slice) — copies top-level only; nested objects/arrays are still shared references. Deep — duplicates the entire tree. Use structuredClone(obj) in modern JS, or write recursive copy with WeakMap to handle circular references.

What is WeakMap?

Like Map but keys must be objects, entries don't prevent garbage collection of key objects, and there's no .size or iteration. Use for attaching private metadata to DOM nodes or objects without causing memory leaks.

Patterns & Live Coding

Debounce vs throttle — when to use each?

Debounce — delays execution until triggers stop for X ms; each new trigger resets the timer. Use: search-as-you-type, resize-end detection. Throttle — executes at most once per X ms regardless of trigger count. Use: scroll position tracking, mousemove, rate-limiting button clicks.

What is currying?

Transforming f(a, b, c) into f(a)(b)(c) — a chain of functions each taking one (or fewer) arguments. Enables partial application: fix some arguments now, supply the rest later. Implementation checks args.length >= fn.length to know when to invoke.

How to implement Function.prototype.bind?

Return a new function that, when called, invokes the original function with: (1) this set to the bound context, (2) pre-filled arguments from bind prepended to any arguments passed at call time. Must preserve the original function's behavior via apply.

How to implement Promise.all?

Return a new Promise. Track a results array indexed by position and a remaining counter. For each input, wrap with Promise.resolve(), on fulfill store result at index and decrement counter — when counter hits 0, resolve with results array. On any reject, immediately reject the outer promise.

Deep clone with circular references?

Recursively copy each property. Maintain a WeakMap mapping original objects to their copies. Before recursing into an object, check the map — if seen, return the existing copy instead of recursing infinitely. Handle Date, RegExp, and arrays as special cases.

What is memoization?

Caching function results keyed by arguments so repeated calls with the same input return instantly from cache. Works best on pure functions (same input → same output, no side effects). Trade memory for speed. Example: caching Fibonacci or expensive API lookups.

DOM & Events

Explain event bubbling and capturing.

When an event fires, it goes through three phases: capturing (window → target), target phase, then bubbling (target → window). Default listeners run in the bubbling phase. Use addEventListener(el, fn, true) or { capture: true } for capture phase.

What is event delegation?

Attach one listener to a parent instead of many on children. On click, check event.target (or closest()) to see which child was clicked. Works for dynamic lists — new children automatically covered. More memory-efficient.

Difference between stopPropagation and preventDefault?

stopPropagation stops the event from traveling to other elements in the bubble/capture chain. preventDefault stops the browser's default action (e.g. following a link, submitting a form) — doesn't stop propagation.

Advanced & Senior

What is a Proxy in JavaScript?

Wraps an object and intercepts operations (get, set, delete, etc.) via handler traps. Used for validation, logging, reactive data (Vue 3), default values. Use Reflect methods inside traps for default behavior.

What are property descriptors?

Metadata on object properties: value, writable (can reassign), enumerable (shows in Object.keys), configurable (can delete/reconfigure). Set with Object.defineProperty. Non-enumerable props are hidden from for...in and Object.keys.

WeakMap vs Map vs WeakSet?

Map: any keys, iterable, has .size. WeakMap: object keys only, not iterable, weak refs allow GC of keys. WeakSet: stores objects weakly — check membership without preventing GC. Use WeakMap/WeakSet for metadata on objects/DOM nodes without memory leaks.

What is AbortController?

API to cancel async operations — pass signal to fetch or custom async code. Call controller.abort() to cancel. Caught as AbortError. Useful for timeouts, user cancellation, cleanup on unmount.

What are hidden classes in V8?

V8's internal object "shapes" — objects with the same properties in the same order share a hidden class for fast property access. Adding/deleting properties or creating objects with different property order creates new shapes and can deoptimize inline caches.

What is tree shaking?

Dead code elimination at build time — bundlers remove unused exports. Requires ESM static import/export (analyzable). CommonJS dynamic require is harder to tree-shake. Vite/Rollup/webpack all support it with ESM.

Name common JavaScript design patterns.

Module (IIFE/ESM encapsulation), Observer (EventEmitter, pub/sub), Factory (functions returning objects), Singleton (one shared instance), Decorator (HOC in React, wrapper functions), Strategy (swappable algorithm functions).

Output & Tricky Questions

What is [] + []?

"" (empty string). The + operator with an object/array triggers toString() — arrays become comma-separated strings, empty arrays become "". Then string concatenation: "" + "".

What is [] == ![]?

true. [] is truthy, so ![] is false. Abstract equality: [] → "" → 0, and false → 0. So 0 == 0 is true.

typeof typeof 1?

"string". typeof 1 returns "number" (a string). typeof "number" returns "string". typeof always returns a string.

console.log(x); var x = 5; — what prints?

undefined, not ReferenceError. Hoisting moves var x to the top and initializes it to undefined before the assignment line runs.

0.1 + 0.2 === 0.3?

false. IEEE 754 floating-point can't represent 0.1 exactly. Result is 0.30000000000000004. Use epsilon comparison: Math.abs(a - b) < Number.EPSILON.

Browser, Memory & Misc

Is JavaScript single-threaded?

The main thread runs one call stack — yes, single-threaded for your JS code. Web Workers and Node worker threads run JS on separate threads with separate stacks and no shared DOM. Async concurrency on main is cooperative via the event loop, not parallel execution.

What causes memory leaks?

Forgotten event listeners, closures holding references to large/detached objects, accumulating global variables, detached DOM nodes still referenced in JS, uncleared setInterval/setTimeout, and unbounded caches. Fix: remove listeners, null references, use WeakMap for object-keyed caches.

for...in vs for...of?

for...in iterates enumerable property keys (strings) on objects — includes prototype chain; avoid on arrays (gives indices as strings). for...of iterates values of iterables — arrays, strings, Map, Set, generators.

What is strict mode?

"use strict" enables stricter parsing and runtime: no accidental global variables, this is undefined in plain function calls, duplicate parameter names are errors, silent failures (assigning to non-writable property) throw. ES modules are strict by default.

null vs undefined?

undefined — variable declared but not assigned, missing function parameter, missing object property, function with no return. null — intentional assignment meaning "no value". typeof undefined is "undefined"; typeof null is "object". In JSON, undefined is omitted; null is preserved.

How does garbage collection work?

Mark-and-sweep: engine starts from roots (global object, call stack variables, closures), marks all reachable objects, then frees unreachable ones. Generational GC optimizes by collecting young objects more often. You cannot manually free memory — drop references when done.

Limitations of JSON.stringify?

Omits: undefined, functions, symbols, and non-enumerable properties. Converts Date to ISO string (not revived as Date on parse). No circular reference support (throws). JSON.parse doesn't restore types — everything becomes plain objects/arrays/strings/numbers/booleans/null.
