Request lifecycle (30-second answer)

Tomcat → DispatcherServlet → HandlerMapping finds @RequestMapping
  → Filters/Interceptors → deserialize @RequestBody + @Valid
  → Controller → Service → Repository → DB
  → Serialize response (Jackson) → back through filter chain

30-second answers

Constructor vs field injection?
Constructor: explicit, final fields, fail-fast, easy to test with plain new(). Field: hidden deps, needs reflection, harder to test.

401 vs 403?
401 = not authenticated at all. 403 = authenticated but not allowed.

Why is default singleton scope risky for state?
One instance shared by every concurrent request thread — mutable instance fields race.

Implement from memory

  • Full CRUD @RestController: GET all/one, POST, PUT, DELETE with correct status codes
  • A @Configuration class with a manual @Bean for a 3rd-party client
  • application.yml with a custom @ConfigurationProperties-bound class
