30-second answers

Why does a partition key matter?
Same key → same partition → guaranteed order for that key (e.g. all events for one orderId).

Why circuit breakers?
Stop cascading failure — a slow downstream service shouldn't exhaust the caller's own threads too.

Why idempotent consumers?
At-least-once delivery can redeliver a message after a crash before offset commit.

Implement from memory

  • A @FeignClient interface + a @CircuitBreaker fallback method
  • A KafkaTemplate producer + @KafkaListener consumer with a groupId
  • Explain topic/partition/offset/consumer group out loud with a concrete example
  • Explain why order events keyed by orderId stay in order
