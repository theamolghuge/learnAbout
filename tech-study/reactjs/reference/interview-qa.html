Basics

What is React?

A JavaScript library for building user interfaces using components. It's declarative — you describe UI as a function of state — and uses a Virtual DOM for efficient updates. It's a library, not a full framework (routing, data fetching are separate choices).

What is the Virtual DOM?

A lightweight JavaScript representation of the UI tree. On state change, React builds a new Virtual DOM, diffs it against the previous (reconciliation), and applies minimal changes to the real DOM. Batching and diffing reduce expensive DOM operations.

What is one-way data flow?

Data flows down from parent to child via props. Children notify parents of changes via callbacks — never mutate parent state directly from child. Keeps data flow predictable and easier to debug.

Function components vs class components?

Function components with hooks are the modern standard — simpler, less boilerplate. Class components use this.state, lifecycle methods, and still needed for Error Boundaries. New code should use functions + hooks.

What is reconciliation?

React's process of comparing the new element tree with the previous one and determining the minimum DOM updates needed. Uses heuristics: different element types replace the subtree; keys identify stable list items across renders.

JSX

What does JSX compile to?

React.createElement(component, props, ...children). Babel (or similar) transforms JSX at build time. React 17+ can use automatic JSX runtime without importing React in every file.

Why use className instead of class?

class is a reserved keyword in JavaScript. JSX uses className to set the HTML class attribute. Same for htmlFor instead of for on labels.

Can you use if statements inside JSX?

Not directly — JSX expressions must be a single expression. Use ternary (cond ? a : b), logical AND (cond && <Comp />), or compute the value in a variable/function before the return.

Why do lists need keys?

Keys help React identify which items changed, were added, or removed. Stable unique keys (usually IDs) preserve component state correctly. Using array index as key causes bugs when list reorders or inserts — state can attach to wrong item.

State & Props

Difference between props and state?

Props are read-only inputs from parent — component cannot change them. State is internal, mutable via setter (setState or useState), and triggers re-render when updated. Both cause re-render when they change (props when parent re-renders).

What is lifting state up?

When two sibling components need the same data, move state to their closest common ancestor. Parent owns state, passes data down as props and callbacks to update. Single source of truth.

Why shouldn't you mutate state directly?

React compares state by reference for re-render decisions. Mutating objects/arrays in place doesn't change reference — React may skip re-render. Always create new objects/arrays: setItems([...items, newItem]) or functional updates.

Controlled vs uncontrolled components?

Controlled: React state drives input value — single source of truth, easy validation. Uncontrolled: DOM holds value via ref — less code for simple forms. File inputs are typically uncontrolled.

Hooks

What are the Rules of Hooks?

Only call hooks at the top level — not inside loops, conditions, or nested functions. Only call from React function components or custom hooks. Ensures hooks run in same order every render.

What does useState return?

A tuple: [currentValue, setterFunction]. Setter can take new value or updater function (prev) => newVal. Updater form is safe when next state depends on previous — e.g. counters, toggles.

Explain useEffect and the dependency array.

Runs side effects after render. Empty array [] = mount only. [dep] = re-run when dep changes. No array = every render (usually wrong). Return a cleanup function for subscriptions, timers, listeners — runs before next effect and on unmount.

useRef vs useState?

useRef holds a mutable value that persists across renders without triggering re-render — DOM refs, timers IDs, previous values. useState triggers re-render when updated — for UI-visible data.

When to use useReducer instead of useState?

Complex state logic with multiple sub-values, next state depending on previous, or when actions are well-defined (ADD, REMOVE, RESET). Similar to Redux pattern locally. useState for simple independent values.

What is a custom hook?

A function starting with use that composes other hooks — extracts reusable stateful logic. Example: useFetch, useLocalStorage. Shares logic, not state — each call gets its own state.

useEffect vs useLayoutEffect?

useEffect runs asynchronously after paint — doesn't block browser. useLayoutEffect runs synchronously after DOM updates, before paint — use for measuring DOM or preventing visual flicker. Default to useEffect.

React Query, Redux & API

When to use React Query vs Redux?

React Query: server/async state — caching, refetching, mutations, pagination. Redux Toolkit: client/global UI state — cart, wizard steps, feature flags. Often used together, not as replacements.

What is a queryKey in React Query?

Unique cache identifier — array like ["users", id]. Used for caching, deduplication, and invalidation. Changing key = separate cache entry.

Explain Redux Toolkit's createSlice.

Generates actions and reducer from a slice definition. Uses Immer internally — you write "mutating" logic that's converted to immutable updates. Includes action creators automatically.

How do you cancel a fetch in useEffect?

Use AbortController — pass signal to fetch, call controller.abort() in cleanup. Ignore AbortError in catch. Prevents setState on unmounted components.

Rendering

What triggers a re-render in React?

State update in the component, parent re-render (child re-renders by default), context value change for consumers, and force update (rare). Props change alone doesn't trigger if parent doesn't re-render.

What is React.memo?

Higher-order component that memoizes a function component — skips re-render if props are shallow-equal to previous. Use when parent re-renders often but child props haven't changed. Pair with useCallback for function props.

Difference between useMemo and useCallback?

useMemo caches a computed value — returns memoized result. useCallback caches a function reference — returns same function if deps unchanged. useCallback is useMemo for functions: useCallback(fn, deps) ≈ useMemo(() => fn, deps).

What is code splitting with React.lazy?

const Page = lazy(() => import('./Page')) — loads component JS on demand. Wrap in <Suspense fallback={...}> while loading. Reduces initial bundle size.

Effects & Lifecycle

How do hooks map to class lifecycle methods?

useEffect(fn, []) ≈ componentDidMount. useEffect with deps ≈ componentDidUpdate for those deps. Cleanup ≈ componentWillUnmount. No exact 1:1 — effects combine mount/update/unmount per dependency set.

What is Strict Mode and why double-invoke effects?

Dev-only wrapper that intentionally double-mounts components and double-runs effects to expose side effects that aren't cleaned up properly. Helps find bugs — production behavior is single run.

What are Error Boundaries?

Class components that catch JS errors in child tree during render — show fallback UI instead of crashing whole app. Use getDerivedStateFromError and componentDidCatch. No hook equivalent yet — still need a class wrapper.

Performance

How do you optimize a slow React list?

Stable keys, virtualization (react-window) for long lists, memoize row components with React.memo, avoid inline object/function props, paginate or infinite scroll instead of rendering thousands of DOM nodes.

What is React 18 automatic batching?

Multiple setState calls in event handlers, promises, timeouts, and native handlers batch into one re-render. Previously only batched in React event handlers. Improves performance — fewer renders.

useTransition vs useDeferredValue?

useTransition wraps state updates you initiate — marks them low priority. useDeferredValue defers a value you're receiving — keeps UI responsive while expensive render catches up. Both for non-urgent updates.

SSR, Hydration & RSC

What are React Server Components?

Components that run only on the server — can access databases directly, zero JS sent to client for that component. No useState/useEffect. Client Components ("use client") handle interactivity. Enables smaller bundles and streaming.

What causes hydration mismatch errors?

Server HTML differs from client's first render — e.g. Date.now(), random IDs, browser-only APIs in initial render, invalid HTML nesting. Fix: render same on server/client, defer browser-only code to useEffect.

Patterns & Architecture

When to use Context vs Redux?

Context: infrequent updates — theme, locale, auth user. Redux/Zustand: complex global state, frequent updates, middleware, devtools, time-travel. Context re-renders all consumers on change — can hurt performance without splitting contexts.

What is prop drilling and how to avoid it?

Passing props through many intermediate layers that don't use them. Fix: Context, component composition (children), state management library, or colocate state closer to where it's needed.

Presentational vs container components?

Presentational: how things look — receive props, no data fetching. Container: how things work — fetch data, manage state, pass to presentational. Pattern less rigid now — hooks often replace containers.

Advanced

What is React Fiber?

React's reconciliation engine rewrite. Enables incremental rendering — work can be split, paused, resumed, and prioritized. Powers concurrent features, Suspense, and smoother UX for heavy updates.

What is the difference between React and ReactDOM?

react — core (components, hooks, createElement). react-dom — renderer for web browsers (createRoot, render). Other renderers exist: react-native, react-three-fiber.

How does React handle synthetic events?

React wraps native browser events in SyntheticEvent for cross-browser consistency. React 17+ attaches listeners to root container, not document — better for micro-frontends. Pooling removed in React 17.

Server-side rendering (SSR) vs client-side rendering (CSR)?

CSR: blank HTML shell, JS loads and renders in browser — slower first paint. SSR: server sends fully rendered HTML — faster first paint, needs hydration. Next.js supports SSR, SSG, and hybrid.

What is hydration?

Attaching React event listeners and state to server-rendered HTML on the client. React expects client render to match server HTML — mismatch causes hydration errors. useEffect for browser-only code avoids mismatches.

Render phase vs commit phase?

Render: call components, build fiber tree, diff — can be interrupted in concurrent mode. Commit: apply DOM mutations, run useLayoutEffect, schedule useEffect — must complete atomically, not interruptible.

How do you optimize Context performance?

Split into smaller contexts (theme vs auth). Memoize provider value with useMemo. Move state down — don't put frequently changing values in wide contexts. Consider Zustand/selectors for granular subscriptions.

Architecture & Production

What is Module Federation?

Webpack 5 feature — apps share modules at runtime without rebuilding. Host app loads remoteEntry.js from another deploy. Enables micro frontends with shared React/component libraries.

What are Core Web Vitals?

LCP (loading), INP (interactivity), CLS (visual stability). Google ranking signals. Target: LCP <2.5s, INP <200ms, CLS <0.1. Measure with Lighthouse, RUM tools.

How do you test React components?

React Testing Library — render, query by role/label (user-centric), fire events with userEvent, assert DOM. Mock API with MSW. E2E with Playwright/Cypress. Storybook for isolated development.

React security best practices?

JSX auto-escapes strings. Sanitize dangerouslySetInnerHTML. Avoid localStorage for tokens (XSS). CSP headers. Validate server-side. Keep dependencies updated. httpOnly cookies for refresh tokens.
