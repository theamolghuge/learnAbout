useEffect cheat sheet ⭐

useEffect(() => { ... }, []);      // mount / unmount
useEffect(() => { ... }, [id]);    // when id changes
useEffect(() => {
  const ctrl = new AbortController();
  fetch(url, { signal: ctrl.signal });
  return () => ctrl.abort();       // cleanup
}, [url]);

30-second answers

useEffect — when and why?
Sync React with external systems — fetch, subscriptions, DOM, timers. Runs after paint. Cleanup prevents leaks. Deps control re-runs.

Why immutable state?
React detects changes by reference. Mutation skips re-render or causes stale UI. Spread/filter for updates.

React Query vs useEffect fetch?
Query handles cache, dedupe, background refetch, loading/error states, invalidation. useEffect fetch is manual — fine for one-offs.

Render vs commit phase?
Render: call components, diff (can interrupt). Commit: apply DOM, run effects (atomic).
